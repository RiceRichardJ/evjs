# Escape Velocity CSV to JSON Data Converter

This tool converts the original Escape Velocity (1996) CSV data exports to JSON format for use in the EVJS JavaScript port.

## Directory Structure

```
data-conversion/
├── in/              # Input CSV files (from original EV data export)
├── out/             # Output JSON files (generated by conversion script)
├── convert-csv-to-json.js    # Main conversion script
└── README.md        # This file
```

## Usage

### Prerequisites

Ensure `csv-parse` is installed:

```bash
npm install
```

### Running the Converter

From the project root:

```bash
node data-conversion/convert-csv-to-json.js
```

This will:
1. Read all CSV files from `data-conversion/in/`
2. Convert each to JSON format
3. Write output to `data-conversion/out/`

### Output Format

Each output file is an ES6 module in the format:

```javascript
export default {
  "resourceType": [
    { /* entry 1 */ },
    { /* entry 2 */ },
    ...
  ]
}
```

### Property Name Transformations

The converter automatically transforms CSV column names to JSON property names:

- **Spaces → camelCase**: "Position X" → `x`, "Position Y" → `y`
- **Size columns**: "Size X" → `w`, "Size Y" → `h`
- **Common patterns**: Columns are converted to camelCase by default

### Special Handling

#### 1. **Sentinel Values**
- `-1` values are treated as sentinels and filtered out when building arrays
- Empty strings are preserved

#### 2. **Flag Decoding**
- Hex flag values (e.g., `0x0081`) are decoded to:
  - Boolean properties
  - String arrays (for booty, info types, etc.)

#### 3. **Array Restructuring**
- Multiple CSV columns are combined into JSON arrays
- Example: `Ship 1-16` columns → `shipTypes: [...]` array

#### 4. **Data Types**
- Numeric values are automatically parsed
- Empty strings remain as empty strings
- Special values are preserved

## Resource-Specific Converters

The script includes specialized converters for:

- **nebu** (Nebulae) - Simple 1:1 mapping
- **dude** (Ship Types) - Complex array restructuring with EVN export correction
- **syst** (Systems) - Array restructuring for links, spobs, and dudes
- **weap** (Weapons) - Flag decoding and optional fields
- **Generic** - Best-effort conversion for other resource types

### EVN Export Column Mapping Issues

⚠️ **CRITICAL**: The CSV files were exported using EVN (Escape Velocity Nova) format, which has incorrect column labels for original EV data.

**düde (DUDE) resource** requires special handling:

| CSV Column Label | Actual Data | Conversion |
|-----------------|-------------|------------|
| `Govt` | Ship1 | (already decimal) |
| `Flags` | Ship2 | **HEX → decimal** |
| `InfoTypes` | Ship3 | **HEX → decimal** |
| `Ship 1` | Ship4 | (already decimal) |
| `Ship 2` | Prob1 | (already decimal) |
| `Ship 3` | Prob2 | (already decimal) |
| `Ship 4` | Prob3 | (already decimal) |
| `Ship 5` | Prob4 | (already decimal) |
| `Ship 6` | Govt | (already decimal) |
| `Ship 7` | Booty | **decimal → 0x0000 hex format** |

Example: CSV row with `0x0093` in "Flags" column is actually Ship2 ID 147 (0x93 = 147 decimal).

## Important Notes

### Manual Review Required

⚠️ **The converted files should be manually reviewed and compared with existing `src/json/` files before integration.**

Reasons:
1. The CSV exports may not be 100% accurate
2. Some manual curation may have been applied to existing JSON
3. Complex flag decoding may need adjustment
4. Array structures may need refinement

### Known Limitations

1. **Complex Formulas**: Speed/acceleration scaling formulas are not applied (would need reverse-engineering)
2. **Flag Mappings**: Only basic flag decoding is implemented
3. **Default Values**: Index 0 entries may need manual adjustment
4. **Data Validation**: No validation against game constants

### Extending the Converter

To add better support for a specific resource type:

1. Add a converter function in `convert-csv-to-json.js`
2. Add it to the `convertRow()` switch statement
3. Reference the Resource Bible PDF for field meanings
